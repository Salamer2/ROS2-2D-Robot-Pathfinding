# ROS2 2D Robot Pathfinding 

This is a course project from Innopolis University. \
A ROS2 project that implements an autonomous agent path planning on the partially known map.
Map viewer was already given, while robot-view visualization was implemented during project completion.

## Requirements

- ROS2 [Humble or newer]
- Python 3.10+
- `numpy`, `opencv-python`, `cv_bridge`
